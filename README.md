# 代码幸存者 Code Survivors

一款 2D 幸存者类（Vampire Survivors-like）游戏，主题是**编程**：你扮演一个"程序"，要在被 Bug 与异常淹没的系统里活下来。

面向学过编程的青少年设计 —— 每个敌人、每把武器都是一个真实的编程概念，首次遇到时会弹出白话知识卡解释它。

---

## 玩法

一局约 20 分钟：怪物一波波涌来，靠消灭它们掉落的经验宝石升级，每次升级三选一拿武器或被动，撑到 18 分钟的 Boss。

- **12 把武器**，每把对应一个编程概念，各有独立机制：指针解引用、断点调试、垃圾回收、缓冲区溢出、永真循环、广播波、分支长鞭、循环护盾、齐射、飞刃、审判、重编译
- **进化系统**：武器满级后可进化，机制发生质变而不只是数值变大
- **5 个角色**，起始武器、属性修正、难度各不相同，按解锁链逐步开放：实习生、测试工程师、算法工程师、全栈工程师、架构师
- **11 类敌人**按时间档位投放（0 分钟"报错" → 8 分钟"内存不足"），6 分钟起有精英，18 分钟 Boss 带五技能轮盘
- **知识卡系统**：43 张白话知识卡，随游戏进程解锁，Tab 键可随时翻开图鉴

## 操作

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| 鼠标左键 | 选择升级卡 |
| Tab | 打开知识卡图鉴 |
| ESC | 暂停 |

## 技术要点

引擎 **Godot 4.7.2**（Compatibility 渲染），GDScript。

- 对象池 + 空间哈希网格 + MultiMesh 批量渲染，同屏上千敌人仍保持流畅
- 零音频文件：16 个音效和 2 首 BGM 全部由代码合成
- 中文字体内嵌（思源黑体），不依赖系统字体
- 数据与表现分离，便于调数值和做自动化验证
- 内置大量自检入口，可用 headless 模式跑整局模拟与多系统回归

## 运行

1. 安装 Godot 4.7.2 Standard
2. 用 Godot 打开本目录下的 `project.godot`
3. 需要发布版本时，用 Godot 导出 Windows 可执行程序

命令行自检（在项目目录执行）：

```
godot --headless -- --smoke=20     跑一局 20 分钟整局模拟
godot --headless -- --evotest      进化系统自检
godot --headless -- --lictest      授权系统自检
```

## 关于激活码

游戏内置 **7 天试用**，从第一次运行开始计算。到期后需要激活码继续游玩，激活码**离线校验、绑定机器**：一码对应一款游戏 + 一台电脑，且只能用一次，到期续期需要新的码。

学生只需把游戏里显示的「申请码」（8 位，只与硬件有关，不含隐私）发给作者，即可换取激活码。

**本仓库不包含密钥**：`core/license_key.gd` 已被 `.gitignore` 排除，clone 下来的游戏照常能玩，只是「输入激活码」功能未配置。如果你想接入自己的发码体系，把 `core/license_key.gd.example` 复制成 `core/license_key.gd` 并填入密钥即可。
